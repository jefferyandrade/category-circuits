# ResNet-50 IMAGENET1K_V2: backup results

Backup results with ResNet-50's IMAGENET1K_V2 checkpoint (`resnet50-11ad3fa6.pth`, 99 shared categories), as this repository held them until the paper switched ResNet-50 to IMAGENET1K_V1 on 4 Nov 2026 (release 1.1.0, commit 606ad66, whose code produced them); each file sits at the path of its IMAGENET1K_V1 counterpart under `data/`, and tables shared with the other networks are kept whole.
